Paletas para el aplicativo MQ

Tres propuestas de azul, anaranjado y café, cada una en tema claro y oscuro. Azul = color principal; anaranjado = acento puntual (pestaña activa, logo, rayas); café = tinta, neutros y superficies cálidas. Las alertas no cambian. Debajo de cada muestra va el contraste medido (WCAG): verde si cumple 4,5:1 para texto (3:1 para lo decorativo).

A · Sitio web

El azul y el anaranjado exactos del sitio inlotrans.com.co; el café hace de tinta y de neutros (en vez del gris azulado de hoy).
